SERVEPANEL 2.7.0 — БЫСТРЫЙ ПЕРЕХОД С 1.0.0
================================================

ВАЖНО: в старой панели 1.0.0 НЕ НАЖИМАЙТЕ «Обновить с GitHub».
Она делает git reset --hard и может стереть новую версию.
Первый переход выполняется один раз по SSH скриптом upgrade.sh.

Архив:  servpanel-2.7.0.tar.gz
SHA256: см. файл servpanel-2.7.0.tar.gz.sha256

1. Скопировать архив на сервер (PowerShell на Windows):

   scp C:\Users\Adm\Desktop\servpanel-fixed\servpanel-2.7.0.tar.gz root@IP:/root/

2. Зайти по SSH и проверить архив:

   ssh root@IP
   cd /root
   sha256sum servpanel-2.7.0.tar.gz
   # должно совпасть с SHA256 выше

3. Распаковать и запустить:

   tar -xzf /root/servpanel-2.7.0.tar.gz -C /root
   bash /root/servpanel-2.7.0/upgrade.sh

   Скрипт сам:
   - проверит новую версию на копии данных и отдельном порту;
   - сделает бэкап панели и снимок конфигов;
   - заменит только код, не трогая данные, .git, AWG, каскад, nginx,
     fail2ban и AdGuard;
   - сохранит .app_settings.json и загруженный APK (.app/);
   - перезапустит pm2 и проверит HTTP;
   - откатится автоматически при ошибке.

4. Открыть панель, войти как admin с прежним паролем.
   Проверить: клиенты, каскад, диагностику и вкладку «Обновление».
   Пароль лежит в /root/servpanel/admin_pass.txt.

5. Новая вкладка «Приложение»:
   - скачать APK Servpanel или загрузить новую сборку;
   - посмотреть адрес для приложения (прямой HTTPS без Nginx);
   - включить отдельный порт метрик (внутренний и внешний).
   Если порт метрик открыт наружу, панель сама создаст токен.
   Подробности — в README.md, раздел «Мобильное приложение и метрики».

   WARP для AdGuard — ОПЦИОНАЛЬНО. Он не ставится автоматически.
   Если нужен: «Службы и DNS» → «Cloudflare WARP для AdGuard» →
   указать IP туннеля (обычно 10.8.1.1) и нажать «Установить WARP + Xray».
   Затем заполнить URL/логин/пароль AdGuard и нажать «Записать правила».
   Если WARP блокируется в РФ, ставьте его на EU-выходе и указывайте
   его туннельный IP. Правила AdGuard можно записать из панели RU-входа:
   WARP на RU при этом не нужен.

6. Новая вкладка «Установка»:
   - AWG ставится стандартно: без выбора пресетов, версия 3.1, порт 443.
     Конфигурацию клиента генерируйте в Архитекторе
     (architect.vai-rice.space/amneziawg), в мастере обфускации панели
     или импортом .conf во вкладке «Обфускация».
   - MTProto: кнопка «Установить MTProto» открывает мастер. Выберите
     Telemt / MTProto.zig / только фикс, домен, порт, ad_tag, пользователя
     и WEB-режим заранее — установщик MEKO пройдёт без вопросов.
     Ссылки tg:// появятся в панели после завершения.
   - Порты для AWG, MTProto, AdGuard и WARP открываются в UFW
     автоматически. Если UFW выключен, правила применятся после включения.

Откат вручную:

   bash /root/servpanel-2.7.0/upgrade.sh --rollback \
     /root/backups/servpanel-pre-update-YYYYMMDD-HHMMSS.tar.gz

Журнал:

   tail -n 100 /var/log/servpanel_update.log

Дальше обновления можно ставить из панели:
«Обновление» → файл servpanel-*.tar.gz (или URL/GitHub).
После первого перехода GitHub-режим может отказаться работать, если файлы
панели отличаются от origin/main — это нормально, используйте файл.
